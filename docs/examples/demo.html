# 素数を数える

まず全体の形だけを述べる。細部はあとまわしにする。 

<<*>>=
#!/usr/bin/env perl
use strict; use warnings;
<<定数の設定>>
<<篩を回す>>
<<結果を表示する>>

上限は 50 にしておく。 

<<定数の設定>>=
my $limit = 50;

$p$ の倍数は $p^2$ から消せばよい。それより小さい倍数は より小さい約数を持つので、すでに消えているからである。 

<<篩を回す>>=
my @composite;
for (my $p = 2; $p * $p <= $limit; $p++) {
    next if $composite[$p];
    <<p の倍数を消す>>
}

内側のループだけを別の節に切り出しておく。 インデントは参照側の位置が引き継がれる。 

<<p の倍数を消す>>=
for (my $q = $p * $p; $q <= $limit; $q += $p) {
    $composite[$q] = 1;
}

生き残ったものが素数である。 

<<結果を表示する>>=
print join(' ', grep { !$composite[$_] } 2 .. $limit), "\n";
